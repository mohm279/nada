نَدى | NADA — صفحات البداية
==========================

الملفات:
- rooms.html: اختيار غرفة الإنشاد بعد الدخول
- library.html: فهرس الأناشيد العام
- nasheed.html: تفاصيل أنشودة
- leader.html: لوحة القائد
- member.html: واجهة المنشد العادي
- admin.html: نقطة بداية للوحة المدير
- shared.js: الاتصال بـ Supabase والتحقق الأولي من الجلسة والتنقل
- schema.sql: بنية قاعدة بيانات أولية

مهم قبل التشغيل:
1) ارفع الملفات إلى نفس مجلد الاستضافة.
2) راجع إعدادات Supabase في shared.js وتأكد أنها تطابق مشروعك.
3) نفّذ schema.sql في SQL Editor بعد مراجعته وملاءمته لقاعدة مشروعك.
4) أنشئ مستخدمي Supabase Auth من لوحة المشروع، ثم اربط كل مستخدم بصف في shared_accounts.
5) فعّل سياسات RLS واختبرها بحسابات كل دور قبل استخدام الموقع الحقيقي.

هذه حزمة بداية مرتبطة بـ Supabase وليست ضمانًا بأن الموقع أصبح جاهزًا للإنتاج بمجرد رفعها؛ يجب تطبيق SQL وإعداد الحسابات والصلاحيات. لا تضع service_role key في أي ملف متاح للمتصفح.
