# 🌿 نَدى | NADA

منصة عربية لتنظيم الأناشيد وإدارتها بين فرق الإنشاد، بواجهة بسيطة تدعم اللغة العربية واتجاه الكتابة من اليمين إلى اليسار.

🔗 **الموقع:** https://nada-inshad.netlify.app

## ✨ مميزات المشروع

- **فهرس الأناشيد:** تصفح الأناشيد والبحث عنها حسب العنوان أو التصنيف.
- **عرض الأناشيد:** فتح كلمات الأنشودة ونسخها.
- **إدارة الأناشيد:** إضافة الأناشيد وتعديلها وحذفها بحسب الصلاحيات.
- **الغرف والفرق:** اختيار غرفة الإنشاد المسموح بها لكل حساب.
- **اختيار الأنشودة النشطة:** يستطيع القائد اعتماد أنشودة للغرفة أو إلغاء اختيارها.
- **واجهة المنشد:** الاطلاع على الأنشودة النشطة ومتابعة اختيار القائد.
- **سجل الاختيارات:** الاحتفاظ بسجل عمليات اختيار الأناشيد وإلغائها وفق إعدادات قاعدة البيانات.
- **البحث والصفحات:** عرض النتائج على دفعات بدل تحميل جميع النتائج دفعة واحدة.

## 👥 الأدوار والصلاحيات

### 1. المدير (Admin)
- إدارة الأناشيد من خلال الإضافة والتعديل والحذف.
- إدارة الفرق والحسابات والصلاحيات بحسب الوظائف المفعّلة في المشروع.

### 2. القائد (Leader)
- الدخول إلى الغرف المسموح بها لحسابه.
- اختيار الأنشودة المعتمدة للغرفة الحالية أو إلغاء الاختيار.
- استخدام الحساب من أكثر من جهاز، مع إمكانية اختيار غرفة مختلفة على كل جهاز.

### 3. المنشد العادي (Member)
- الاطلاع على الأنشودة النشطة في الغرفة الحالية.
- متابعة التغييرات التي يجريها القائد.
- استخدام الحساب من أكثر من جهاز، مع استقلال اختيار الغرفة على كل جهاز.

### 4. الزائر
- تصفح فهرس الأناشيد وعرض كلماتها ونسخها وفق إعدادات الوصول العامة في قاعدة البيانات.
- لا يملك صلاحيات الإدارة أو اعتماد الأناشيد للغرف.

## 📁 ملفات المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | صفحة الدخول |
| `rooms.html` | اختيار غرفة الإنشاد |
| `library.html` | فهرس الأناشيد العام |
| `nasheed.html` | عرض تفاصيل الأنشودة وكلماتها |
| `admin.html` | لوحة المدير |
| `leader.html` | واجهة القائد |
| `member.html` | واجهة المنشد العادي |
| `shared.js` | الاتصال بـ Supabase والوظائف المشتركة والتحقق من الجلسة |
| `schema.sql` | ملف تأسيسي لبنية قاعدة البيانات |

## 🛠️ التقنيات المستخدمة

- HTML
- CSS
- JavaScript
- Supabase للمصادقة وقاعدة البيانات والصلاحيات
- GitHub لإدارة ملفات المشروع
- Netlify لاستضافة الموقع

## 🔐 الأمان

- تُستخدم مصادقة Supabase للتحقق من جلسات المستخدمين.
- تعتمد صلاحيات البيانات على إعدادات Row Level Security (RLS) وسياسات قاعدة البيانات والدوال المخصصة.
- لا ينبغي منح الزائر أو المستخدم العادي صلاحيات تعديل البيانات أو حذفها.
- يمنع وضع مفتاح `service_role` في ملفات الواجهة الأمامية أو أي ملف متاح للزوار.
- يجب اختبار سياسات الوصول والصلاحيات قبل إجراء تغييرات أمنية على قاعدة البيانات.

## 🚀 التشغيل والتحديث

1. افتح ملفات المشروع في محرر مثل Visual Studio Code.
2. تأكد من إعداد عنوان مشروع Supabase والمفتاح العام المخصص للاستخدام في المتصفح داخل `shared.js`.
3. تأكد من وجود الجداول والدوال والسياسات المطلوبة في مشروع Supabase.
4. اختبر تسجيل الدخول والصلاحيات واختيار الغرف واعتماد الأناشيد.
5. ارفع التعديلات إلى مستودع GitHub المرتبط بالموقع.
6. تحقق من اكتمال النشر على Netlify ثم اختبر الموقع بعد التحديث.

> **ملاحظة:** ملف `schema.sql` ملف تأسيسي، وليس بالضرورة وصفًا كاملًا لقاعدة البيانات الحالية. لا تعِد تنفيذه على قاعدة بيانات قائمة قبل مراجعة محتواه ومقارنته بالجداول والدوال والسياسات الموجودة.
